# Super Market Sales Dashboard

An interactive Excel dashboard analyzing supermarket sales from 2015 to 2018, with Region and Month filters.

## Key numbers
- Total sales: 2,260,994
- Number of orders: 9,800

## Dashboard sections
- Sales over the years
- Sales by customer segment
- Top sub-categories
- Sales by state
- Categories by region

## Tools
Excel (Pivot Tables, Slicers, Dashboard)

- super market.xlsx: the dashboard workbook
